## 设计原则（Design Principles）

> 本节与 PRD 第 1 章「设计原则」对齐，作为 UI 措辞与命名的全局约束。

| 编号 | 原则 | 说明 |
|------|------|------|
| **DP-1** | 后台是给公司内部人员使用的，不是专门给管理员用的 | 后台管理系统面向 YT 公司内部人员（系统管理员 / 内容编辑 / 客服），**不限于管理员使用**。UI 措辞、菜单项、按钮文案、角色名中不得使用 `管理员` / `Admin` 等表述。 |
| **DP-2** | `sys_users` 是用户表，不代表仅供管理员使用 | 用户管理界面标题为「用户管理」（非「账号管理」）；菜单项「用户列表」（非「账号列表」）；弹窗「新增用户」（非「新增账号」）。 |

**UI 措辞对照**：

| ❌ 旧措辞 | ✅ 新措辞 |
|----------|----------|
| 管理员登录 | 内部人员登录 |
| 账号管理 | 用户管理 |
| 账号列表 | 用户列表 |
| 新增账号 | 新增用户 |
| 编辑账号 | 编辑用户 |
| 删除账号 | 删除用户 |
| 启停账号 | 启停用户 |
| 初始 admin 账号 | 初始 sysadmin 用户 |

## 1. 设计概述

### 1.1 设计目标
1. 为 YT 家具品牌建立**统一、克制、有质感**的视觉语言，传递"匠心、从容、现代"的品牌气质；
2. 前台聚焦 C 端消费者的**信息获取效率**（快速了解品牌 / 产品 / 招聘 / 联系）；
3. 后台聚焦内部人员的**操作效率**（表格化、快捷操作、权限清晰）；
4. 前台与后台共用同一设计 token，保证品牌一致性，同时后台布局更紧凑（信息密度高）。

### 1.2 设计原则
| 原则 | 说明 |
|------|------|
| **少即是多** | 留白充足，去除装饰性冗余，让产品图与内容成为视觉主体 |
| **木色为骨** | 胡桃木暖棕为主色，米白为底，墨色为文字——呼应家具材质与居家温度 |
| **信息分层** | 标题（衬线）→ 正文（无衬线）→ 辅助信息（浅色），层级一目了然 |
| **效率优先** | 后台表格化呈现 + 行内快捷操作 + 弹窗表单，减少页面跳转 |
| **权限可见** | 后台菜单 / 按钮随 RBAC 权限动态显隐，无权操作明确反馈 |

### 1.3 风格定位
- 前台：**现代简约 + 居家温度**（大图氛围、圆角卡片、柔和阴影）
- 后台：**Ant Design 式管理布局**（深色侧边栏 + 白底内容区 + 表格主导）
- 两端的共同锚点：胡桃木主色 + 墨色侧边栏 + 6px 圆角体系

## 2. 设计系统（Design Tokens）

### 2.1 色彩系统

#### 品牌色板（主色系）
| Token | 色值 | 用途 |
|-------|------|------|
| `--walnut` | `#7A5C3E` | 主色（按钮 / 激活态 / 品牌标识 / 图表主线） |
| `--walnut-dark` | `#5F4730` | 主色深（hover / 渐变底 / Hero 背景） |
| `--cream` | `#FAF7F1` | 页面主背景（暖米白） |
| `--sand` | `#F0EAE1` | 次级背景（区块分隔 / 标签底 / 图标底） |
| `--line` | `#E5DCCE` | 边框 / 分隔线 |
| `--ink` | `#2B2520` | 主文字（墨色，近黑暖调） |
| `--ink-soft` | `#6E675E` | 次级文字（描述 / 辅助信息） |

#### 功能色（语义色）
| Token | 色值 | 用途 |
|-------|------|------|
| `--white` | `#FFFFFF` | 卡片底 / 弹窗底 / 深色背景上文字 |
| `--green` | `#3E6B45` | 成功 / 启用 / 已处理状态 |
| `--red` | `#C0392B` | 危险操作 / 停用 / 必填星号 / 错误 |
| `--p1` | `#B98A4E` | P1 规划模块标签 |
| 新留言徽标 | `#C0392B` | 后台侧边栏未读数徽标（沿用红） |

#### 状态色建议
| 状态 | 背景 / 前景 |
|------|-------------|
| 上架 / 启用 / 招聘中 / 已联系 | `#EDF3EC` 底 + `#3E6B45` 文 |
| 下架 / 停用 / 已关闭 | `#F6EBEA` 底 + `#C0392B` 文 |
| 新（留言） | `#FDF3E3` 底 + `#B0762A` 文 |
| 已处理 | `#F0EDE8` 底 + `#6E675E` 文 |

> **对比度约束**：正文文字与背景对比度 ≥ 4.5:1（`#6E675E` 在 `#FAF7F1` 上 ≈ 5.2:1，达标；不得使用更浅的灰做正文）。

### 2.2 字体系统

| 层级 | 字体族 | 字号 | 行高 | 字重 | 用途 |
|------|--------|------|------|------|------|
| 标题 1 | 衬线 `Noto Serif SC / Songti SC / SimSun` | 36-52px | 1.25 | 600 | 首页 Hero、页面 Banner 大标题 |
| 标题 2 | 衬线 | 28-32px | 1.4 | 600 | 区块标题（产品系列 / 最新产品） |
| 标题 3 | 衬线 | 17-22px | 1.5 | 600 | 卡片标题（产品 / 新闻 / 职位） |
| 正文 | 无衬线 `-apple-system / PingFang SC / Microsoft YaHei` | 15px | 1.7-1.9 | 400 | 段落正文 |
| 辅助 | 无衬线 | 12-13.5px | 1.6 | 400 | 描述 / 时间 / 标签 / 表格 |
| 按钮 / 导航 | 无衬线 | 14-15px | 1 | 500-600 | 交互元素 |

> **规范**：标题用衬线（营造居家、书卷气质），正文用无衬线（保证可读性）；禁用 Arial / Inter 等通用字体作为品牌字体。

### 2.3 间距与栅格

| 规范 | 值 | 说明 |
|------|-----|------|
| 间距基准 | 8px | 所有间距为 8 的倍数（8 / 16 / 24 / 40 / 56 / 88） |
| 内容容器 | 前台 max-width 1200px；正文阅读宽度 max 860px | 居中，左右 padding 24px |
| 区块垂直间距 | 前台 section 88px；后台 content padding 26px | 后台密度更高 |
| 卡片间距 | 前台网格 gap 22px；后台表格行 padding 12px | |
| 栅格 | 前台卡片网格 4 列（产品 / 系列），≥960px 断点降为 2 列 | 新闻 3 列 |

### 2.4 圆角 · 边框 · 阴影

| Token | 值 | 用途 |
|-------|-----|------|
| 圆角-小 | 4-6px | 按钮 / 输入框 / 标签 / 表格 |
| 圆角-中 | 10-12px | 卡片 / 弹窗 / 上传区 |
| 边框 | 1px `#E5DCCE` | 卡片 / 表格 / 输入框 |
| 阴影-卡片 | `0 10px 30px rgba(43,37,32,.08)` | 卡片 hover / 下拉 / 弹窗 |
| 阴影-弹窗 | `0 20px 60px rgba(0,0,0,.25)` | 后台 Modal |

### 2.5 图标规范

| 规范 | 值 |
|------|-----|
| 图标集 | 统一线性 SVG（stroke 1.6），不使用 emoji 作图标 |
| 尺寸 | 常规 17-22px；图标按钮 20px；大图标容器 46-72px（圆角 10-18px + `--sand` 底） |
| 语义 | 图标仅作辅助，不单独承载关键信息（配合文字） |
| 来源建议 | Heroicons / Lucide 线性图标集 |

## 3. 组件规范

### 3.1 按钮
| 类型 | 样式 | 场景 |
|------|------|------|
| 主按钮 `btn-primary` | 实心 `#7A5C3E` + 白字；hover `#5F4730` | 主行动（提交 / 保存 / 新增） |
| 次按钮 `btn-default` | 白底 + 边框 `#E5DCCE`；hover 边框变主色 | 次要行动（取消 / 重置） |
| 幽灵按钮 `btn-ghost` | 透明底 + 主色描边；hover 填充主色 | 前台导航区辅助 CTA |
| Hero 按钮 `btn-hero` | 白底深字 / 白描边透明底 | 首页大图区 CTA |
| 危险按钮 `btn-danger` | 白底 + 红描边；hover 填充红 | 删除 / 停用 |
| 小按钮 `btn-sm` | padding 5px×12px，字号 12.5px | 表格行内操作 |

> 规范：禁用态使用 `opacity:.5` + 禁止光标；加载中禁用并显示 loading 态（见 8 节）。

### 3.2 导航
**前台顶部导航**
- 结构：Logo（方块标 + 品牌名）+ 5 项主导航 + 右侧 CTA；
- 主导航 hover 显示二级下拉（白底卡片 + 阴影，箭头旋转 135°）；
- 激活态：主色文字 + 字重 600；P1 项带橙色小标签；
- 移动端（≤640px）：汉堡菜单展开全屏列表，二级导航折叠展开。

**后台侧边栏**
- 深色 `#2B2520` 底，宽 220px（≤900px 收为 64px 图标栏）；
- 菜单分组（总览 / 内容管理 / 客户线索 / 系统管理）；
- 激活项：主色填充白字；hover：白 8% 透明底；
- **RBAC 联动**：菜单按当前角色权限码显隐（US-15 / G-13）；留言菜单带未读数红色徽标。

**面包屑**：后台顶栏左侧，格式"一级 / 二级 / 当前页"，当前页加粗。

### 3.3 卡片
| 卡片 | 组成 | 交互 |
|------|------|------|
| 系列卡 | 渐变图（170px）+ 名称 + 描述 + 数量角标 | hover 上浮 6px + 阴影 |
| 产品卡 | 图（200px，左上角标签）+ 名称 + 型号 + 系列/分类 | hover 上浮 + 阴影 |
| 新闻卡 | 日期（主色）+ 衬线标题 + 摘要 | hover 上浮 |
| 新闻列表项 | 左日期块（大字日/月）+ 标题 + 摘要 | hover 边框变主色 |
| 职位卡 / 列表项 | 标题 + 类型/部门/地点标签 + 时间 | hover 上浮 |
| 后台统计卡 | 标签 + 大数字（衬线 30px 主色）+ 环比 | — |
| 角色卡（后台） | 角色名 + 编码角标 + 职责 + 权限摘要 | — |

### 3.4 表格（后台）
- 表头：12.5px 浅色文字 + `#FBFAF7` 底 + 底边框；
- 单元格：13.5px，行 padding 12px，行 hover 微亮底；
- 操作列：文字链接（主色），危险操作为红色；`op-links` 间距 10px；
- 状态：圆角胶囊标签（见 2.1 状态色）；
- 缩略图：52×52 圆角渐变占位（正式环境为对象存储图）；
- 分页：右对齐，页码方形按钮，激活主色填充。

### 3.5 表单
| 元素 | 规范 |
|------|------|
| 输入框 / 下拉 / 文本域 | padding 10-12px；边框 `#E5DCCE`；底 `#FAF7F1`；focus 边框主色 + 底转白 |
| 标签 | 13px 常规，必填项名后红 `*` |
| 上传区 | 虚线主色边框 + 圆角 8px + 主色文字；hover 底变 `--sand` |
| 富文本 | 支持加粗 / 标题 / 图片插入 / 列表（PRD H-09） |
| 校验反馈 | 提交时校验必填；错误提示就近显示红色文案 |
| 防刷提示 | 前台留言底部灰字说明"60 秒内仅可提交一次" |

### 3.6 弹窗（Modal，后台）
- 遮罩：`rgba(43,37,32,.45)`；弹窗宽 640px（窄表单 440px），圆角 12px；
- 头部：标题 + 关闭 ×；底部：取消 / 主操作按钮右对齐；
- 场景：新增/编辑产品、新闻、轮播图、职位、用户，留言详情，修改密码。

### 3.7 标签与状态
- `tag`：11px 圆角小标签（`--sand` 底）；P1 规划用 `tag p1`（橙底橙字）；
- `status`：12px 圆角胶囊（见 2.1 状态色）；
- 后台菜单徽标：红色胶囊数字（新留言数）。

### 3.8 图表（后台工作台）
- 折线图：主线 `#7A5C3E` 2.5px + 数据点同色圆点 + 虚线网格 + 数值标注；
- 柱状图：柱体 `#C9BBA0`（浅木色）+ 日期轴浅灰字；
- 规范：图表仅为辅助表达，同时提供表格数据；颜色对比 ≥ 4.5:1（文字）。

### 3.9 提示 Toast
- 位置：顶部右下；背景墨色白字；圆角 8px；显示 2.6s 自动消失；
- 用途：保存成功、操作反馈、权限 403 提示。

## 5. 交互规范

### 5.1 前台交互
| 场景 | 行为 |
|------|------|
| 导航 | 主导航 hover 展开二级下拉（0.22s 过渡）；点击切换页面并回到顶部 |
| 产品筛选 | 点击分类胶囊即时过滤网格（激活态主色填充） |
| 图片切换（详情页） | 点击缩略图切换主图，激活缩略图主色描边 |
| 留言表单 | 必填校验 → 提交成功显示绿色成功条（4s 自动消失）；60s 内重复提交提示"提交过于频繁"（PRD E-04） |
| 空态 | 无产品/无新闻显示"暂无XXX"提示，不报错（PRD C-06 / D-03） |
| 移动端 | ≤640px：汉堡菜单；网格降为 2 列；新闻列表项纵向排列 |

### 5.2 后台交互
| 场景 | 行为 |
|------|------|
| 登录 | 选择角色 → 登录 → 按 RBAC 渲染菜单（演示：system/editor/service 三档） |
| 权限拦截 | 无权限访问模块：Toast 提示"RBAC 校验，返回 403"，页面不跳转 |
| 弹窗 | 打开/关闭即时；保存成功 Toast 反馈并关闭 |
| 留言状态流转 | 详情弹窗内"标记已联系 / 已处理"；侧边栏未读数实时更新 |
| 危险操作 | 删除需二次确认（原型以 Toast 示意）；停用/删除当前系统管理员用户被禁止（PRD G-08） |
| 分页 | 页码点击切换；当前页主色填充 |
| 修改密码 | 旧密码校验通过才允许更新（PRD G-05） |

## 10. 后续优化建议（P1/P2）

1. **设计 token 落地**：开发时将本节 token 映射为 CSS 变量（前端）与 Ant Design 主题变量（后台 `ConfigProvider` 定制主色），保证两端一致；
2. **正式图片体系**：原型中产品图/轮播图为渐变占位，正式环境替换为对象存储真实素材（OQ-4）；
3. **地图组件**：联系我们页地图占位，P1 接入高德/腾讯地图（PRD E-02）；
4. **动效统一**：定义标准过渡时长（150-300ms）与入场动画（首页加载分段显现）；
5. **暗色模式**：P2 评估（当前仅亮色，符合 PRD 仅中文/无多主题范围）；
6. **组件库沉淀**：待功能稳定后，将重复组件（表格/弹窗/表单）抽取为内部组件库，提升迭代效率。
