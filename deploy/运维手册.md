# YT 家具官网 · 运维手册

## 1. 服务管理

### systemd
```bash
systemctl status yt-api          # 状态
systemctl restart yt-api         # 重启
journalctl -u yt-api -f          # 实时日志
tail -f /var/log/jiaju/api.log   # 访问日志
```

### Docker
```bash
cd deploy && docker compose ps
docker compose logs -f api
docker compose restart api
```

## 2. 备份与恢复

### 每日备份
- 脚本：`api/scripts/backup.py`（复制 data/yt.sqlite → `scripts/backups/yt_YYYYMMDD.sqlite`，保留 7 天）
- cron：见 `deploy/README.md` 第五节
- 生产建议：将备份目录同步至对象存储（OSS/COS）异地保存

### 恢复
```bash
# 停服 → 覆盖 → 起服
systemctl stop yt-api
cp scripts/backups/yt_20260826.sqlite data/yt.sqlite
systemctl start yt-api
```

## 3. 数据库

- 开发/生产均为 SQLite 单文件：`api/data/yt.sqlite`（沙箱环境下 `*.db` 后缀会被写保护，故用 `.sqlite`；正常环境可改回 `data/yt.db`）
- **注意**：SQLite 不适用高并发，MVP 量级足够；若流量增长，迁移 PostgreSQL：
  - 表结构见 `docs/数据库设计文档-YT家具官网.md` §5.4
  - 修改 `config.DATABASE_URL` 为 `postgresql://user:pass@host/db`，TEXT 时间戳 → TIMESTAMP
- 初始化（幂等，重跑安全）：`python scripts/init_db.py`
- 校验（表/索引/种子）：`pytest tests/test_init_db.py`

## 4. 日志与监控

- 访问日志：uvicorn 输出至 `/var/log/jiaju/api.log`；5xx 含堆栈，4xx 为 WARN
- 监控（P1 接入简单探活即可）：
  ```bash
  curl -s https://www.yt-domain.com/api/health
  ```
- 建议：crontab 每 5 分钟探活，失败重启：
  ```bash
  */5 * * * * curl -fsS http://127.0.0.1:8000/api/health >/dev/null || systemctl restart yt-api
  ```

## 5. 账号与权限

- 初始账号 `10000`，密码来自 `INIT_SYSADMIN_PASSWORD`（首次部署设置，登录后建议立即修改）
- 三角色：system（全权限）/ editor（内容）/ service（留言+统计）
- **权限变更即时生效**：改角色/停用后，用户下次请求即 401，前端 `auth/me` 检测强制登出

## 6. 升级流程

```bash
# 1. 备份
cd /var/www/jiaju/api && .venv/bin/python scripts/backup.py
# 2. 拉代码
git pull origin develop
# 3. 依赖（如有更新）
.venv/bin/pip install --no-index --find-links ../dependency/api/wheels -r ../dependency/api/requirements.txt
# 4. 数据库（幂等建表/种子，如需）
.venv/bin/python scripts/init_db.py
# 5. 前端/后台重新构建（如前端有变更）
cd ../frontend && npm run build && cd ../backend && npm run build
# 6. 重启
systemctl restart yt-api && nginx -t && systemctl reload nginx
# 7. 冒烟
curl -s https://www.yt-domain.com/api/health
```

## 7. 安全提示

- `JWT_SECRET` 必须为强随机值且保密（生产覆盖默认值）
- `CAPTCHA_BYPASS` 生产必须为 `false`
- 上传文件白名单 jpg/png/webp ≤5MB，路径按日期+UUID 隔离
- 富文本已由前端 DOMPurify 清洗；后台富文本输入方为可信内部人员
- CORS 白名单仅放行 www/sys 域名，勿用 `*`
